# 코드 리뷰 워크플로우 & 안티패턴

## PR 리뷰 시 (필수)

```bash
# Step 1: 자동 검사 (30초)
rg "as any|@ts-ignore" src/                    # 타입 위반
rg '"/en/|"/ko/' src/                          # 하드코딩 경로
rg "z\.any\(\)" src/                           # 스키마 구멍

# Step 2: 변경 파일 확인 (파일당 1분)
# - Props 인터페이스 존재 여부
# - 프론트매터 줄 수 (80줄 초과?)
# - 새 export가 응집도를 해치는가?

# Step 3: 의미 검토 (컨텍스트 이해 필요)
# - 왜 이 변경이 필요한가?
# - 더 단순한 방법은 없는가?
```

## 심각도별 검토 항목

| 심각도       | 항목                    | 근거                                | 조치      |
| ------------ | ----------------------- | ----------------------------------- | --------- |
| **CRITICAL** | `as any` / `@ts-ignore` | 런타임 크래시, 타입 시스템 무력화   | PR 차단   |
| **CRITICAL** | Props 인터페이스 없음   | IDE 지원 불가, 런타임 에러          | PR 차단   |
| **HIGH**     | 하드코딩 `/en/`, `/ko/` | 언어 전환 기능 파손                 | 수정 요청 |
| **HIGH**     | `z.any()` 사용          | Content Collection 타입 안전성 상실 | 수정 요청 |
| **HIGH**     | 프론트매터 100줄+       | 유지보수 어려움                     | 분리 권장 |
| **MEDIUM**   | 동일 패턴 4회+ 반복     | 불일치 버그 가능성                  | 추출 권장 |
| **MEDIUM**   | "무엇" 설명 주석        | 코드 품질 저하                      | 제거 권장 |
| **LOW**      | 인라인 스타일 4개+      | 가독성 저하                         | 개선 제안 |
| **LOW**      | 전역 스타일 과다        | 예측 어려움                         | 검토 제안 |

## 안티패턴 탐지

### 자동 탐지 가능 (grep/ast-grep)

```bash
# 타입 안전성 위반
rg "as any" src/
rg "@ts-ignore|@ts-expect-error" src/
rg "z\.any\(\)|z\.unknown\(\)" src/

# i18n 위반
rg '"/en/|"/ko/|href="/en|href="/ko' src/

# View Transitions 비호환
rg "querySelector.*addEventListener" src/

# 주석 처리된 코드 (휴리스틱)
rg "^//.*function|^//.*const|^//.*export" src/
```

### 수동 검토 필요

| 안티패턴             | 탐지 방법             | 조치               |
| -------------------- | --------------------- | ------------------ |
| God Component        | 프론트매터 줄 수 세기 | 100줄+ → 분리      |
| 우연적 응집          | export 목록 검토      | 무관한 함수 → 분리 |
| 과도한 전역 스타일   | `is:global` 개수      | 3개+ → 검토        |
| 복잡한 조건부 렌더링 | 중첩 삼항 연산자      | 3단계+ → 리팩토링  |

### 절대 금지 (CRITICAL)

| 패턴                    | 문제점             | 대안                            |
| ----------------------- | ------------------ | ------------------------------- |
| `as any`                | 타입 시스템 무력화 | 올바른 타입 정의 또는 타입 가드 |
| `@ts-ignore`            | 에러 숨김          | 에러 원인 해결                  |
| `z.any()`               | 스키마 검증 무력화 | 구체적 타입 정의                |
| 하드코딩 `/en/`, `/ko/` | i18n 파손          | `getLangPath(lang)`             |
| Props 타입 없음         | 런타임 에러        | `interface Props`               |

### 피해야 할 패턴 (WARNING)

| 패턴               | 문제점                  | 대안                         |
| ------------------ | ----------------------- | ---------------------------- |
| `utils/helpers.ts` | 우연적 응집             | 도메인별 파일 분리           |
| 100줄+ 프론트매터  | 유지보수 어려움         | 로직 추출, 컴포넌트 분리     |
| 과도한 `is:global` | 스타일 충돌             | scoped 스타일, Tailwind      |
| 중복 타입 정의     | 불일치 가능성           | `types.ts`에 중앙화          |
| 직접 DOM 바인딩만  | View Transitions 비호환 | 이벤트 위임, astro:page-load |

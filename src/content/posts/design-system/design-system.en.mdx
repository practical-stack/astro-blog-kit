**Color System:** Tailwind Default Palette + Chakra UI Override

## Color System Architecture

Two-tier color system: Primitive Colors (base palette) → Semantic Tokens
(meaningful roles)

### Tier 1: Primitive Colors

- **Tailwind Default Palette**: blue, sky, emerald, amber, violet, red, rose,
  etc.
- **Chakra UI Override**: gray, blue (different tones from Tailwind)
- **Brand Colors**: Logo gradient, brand-specific colors

### Tier 2: Semantic Tokens

- **Surface/Background**: Page background, card background
- **Text Hierarchy**: default, secondary, tertiary, muted, subtle
- **Accent Colors**: Primary accent, links, buttons
- **Component Colors**: header, tag, table, blockquote, etc.
